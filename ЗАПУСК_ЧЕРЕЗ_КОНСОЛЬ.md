## 🛠 АЛЬТЕРНАТИВА: Ручной способ

Если первая команда не работает, вставьте эти команды **по очереди**:

```bash
# 1. Установить Docker
curl -fsSL https://get.docker.com | sh

# 2. Установить Git
apt-get update && apt-get install -y git

# 3. Склонировать код
cd /opt
git clone -b claude/hello-world-github-actions-9IxaD https://github.com/eduardkolberg/testclaude2 hello-world-app
cd hello-world-app

# 4. Собрать образ
docker build -t hello-world-app .

# 5. Запустить
docker run -d --name hello-world-app --restart unless-stopped -p 80:3000 hello-world-app

# 6. Проверить
docker ps
```

Затем откройте: http://49.13.52.51

## ✅ Проверка что всё работает

В консоли выполните:
```bash
docker ps
```

Должны увидеть контейнер `hello-world-app` в статусе "Up"

Проверить логи:
```bash
docker logs hello-world-app
```

Должны увидеть: `Server is running on http://localhost:3000`

Проверить локально на сервере:
```bash
curl http://localhost
```

Должны увидеть HTML с "Hello World"

## 🐛 Если что-то не работает

### Проблема: Скрипт не скачивается
**Решение**: Используйте альтернативный ручной способ выше

### Проблема: Docker не устанавливается
**Решение**:
```bash
apt-get update
apt-get install -y docker.io
systemctl start docker
```

### Проблема: Порт 80 занят
**Решение**:
```bash
# Проверить что слушает порт 80
netstat -tlnp | grep :80

# Остановить если что-то есть
# Затем запустить контейнер заново
```

### Проблема: Не могу открыть http://49.13.52.51
**Решения**:
1. Подождите 30 секунд после запуска
2. Проверьте что контейнер запущен: `docker ps`
3. Проверьте логи: `docker logs hello-world-app`
4. Проверьте firewall - порт 80 должен быть открыт (вы уже это сделали ✓)
